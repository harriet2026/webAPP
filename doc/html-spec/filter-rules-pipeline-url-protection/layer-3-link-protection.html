与 0709「点击时复检策略」的关系

0709 需求要求在"点击时安全策略（固定）"下方新增可配置的「点击时复检策略」块（M1 回扫黑名单 / M2 查询情报 / M3 深度复检 + M3.1 超时上限 10-120s / M3.2 超时兜底 / M3.3 等待体验 / M3.4 允许用户跳过），深度复检引擎按形态区分（AI 版=钓鱼邮件智能体，传统版=URL沙箱）。当前 demo 未实现该块（差异 D-002、需确认 Q3），本层不提供其预览，落地时以 0709 文档为准补充。
