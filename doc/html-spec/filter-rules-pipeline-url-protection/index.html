4. 数据模型与 API 映射

type Direction = "receive" | "send" | "internal"
type SandboxActionType = "isolate" | "block" | "mark" | "discard"
type TimeoutActionType = "continue" | "treat_malicious" | "pass"

interface UrlSandboxConfig {
  enabled: boolean               // 沙箱检测开关，默认 true
  maliciousAction: SandboxActionType  // 默认 receive→isolate，send/internal→block
  timeoutAction: TimeoutActionType    // 默认 continue
  localIntelEnabled: boolean     // 默认 true
  intelCleanupDays: number       // 默认 180，范围 30-365
  cloudIntelEnabled: boolean     // 默认 true
}
interface LinkProtectionConfig {
  enabled: boolean               // 默认 true
  knownMaliciousPolicy: "block_alert"  // 固定
  unknownPolicy: "block_alert"         // 固定
}
interface UrlProtectionConfig {
  sandbox: Record<Direction, UrlSandboxConfig>  // 按方向存储
  linkProtection: LinkProtectionConfig           // 全局（不分方向）
}
PRD API / 数据表用途落地映射建议需确认
GET/PUT /api/config/url-protection?direction=按方向读写模块配置属管理员可见可改配置——按 implement.md/CLAUDE.md 优先走配置系统（ConfigManager，/apiserver.cf/<section>/<key> + DB config_overrides），不必新增专用 API。Q4：配置存储路径与租户维度
POST /api/sandbox/analyze提交 URL 沙箱分析后端内部对接沙箱引擎（HTTP API 异步），不暴露前端 API。Q6：沙箱引擎与云端情报上游服务现状
GET /api/intel/query?url=查询 URL 情报本地缓存（Redis + DB 持久化）+ 云端查询降级（>5s 降级本地），内部链路。Q6
GET /api/link-protect/redirect?token=链接保护点击重定向网关需提供公网可达的 safelink 重定向端点（原始 URL 加密编码进 token），命中→警告页，安全→302。Q7：safelink 域名/证书/部署形态
处置动作 isolate/block/mark/discard沙箱恶意 URL 处置复用统一规则系统 action：isolate→quarantine，block→reject，mark→accept+添加风险 header（不新增 mark action），discard→discard。Q2：mark 的 header 约定
url_protection_config / url_intel_cache / url_detection_log / url_click_logPRD 设计表非硬性要求；配置并入 config_overrides；情报缓存/检测日志/点击日志需评估复用现有日志体系（JSONL/DB）。"PostgreSQL 存储"非硬性，需支持全部信创后端。Q6/Q7
