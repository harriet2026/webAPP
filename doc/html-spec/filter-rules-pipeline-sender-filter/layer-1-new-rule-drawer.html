配置提示

  • 优先级越小越先匹配
  • 支持通配符如 *@domain.com
  • 留空有效期表示永久有效
  • 群组和组织来自群组策略配置

元素清单

区域元素默认值/占位符交互行为
头部标题新建规则新建态；编辑态切换为“编辑规则”。
头部取消 / 保存右上角按钮取消有脏数据时触发未保存确认；保存执行校验。
基础设置规则名称如：可疑发件人必填，空值保存提示“规则名称不能为空”。
基础设置发信人类型个人可选个人/群组/组织域名；切换会清空当前发信人值。
基础设置发信人输入如: user@example.com 或 *@domain.com个人类型必填；群组/组织时替换为 Select。
基础设置发信IP范围全部IP可选全部IP/IP组/单IP/IP段；后3项会显示额外控件。
基础设置有效期至空，日期选择留空表示永久。
基础设置优先级2000，范围 2000-2049数值越小越先匹配。
执行动作动作 Select黑名单默认阻断黑名单可选阻断/隔离/审核；白名单仅允许放行。
