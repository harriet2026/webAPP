3D“使用该示例”运行时缺陷（浏览器实测）

点击配置示例卡上的“使用该示例”按钮，控制台抛出：

Uncaught ReferenceError: setSkipSpf is not defined

源码 onClick 调用 setSkipSpf(example.config.skipSpf)，但 SenderFilterDrawer 内并无 setSkipSpf 状态，example.config 也只含 action/ipRangeType。结果：示例配置未被应用，抽屉保持打开，无 Next.js 崩溃遮罩（错误被 React 事件系统吞掉）。

PRD 期望demo 实际落地建议
点击一键填充示例配置（动作/IP范围等）到表单抛 ReferenceError，示例未应用移除 setSkipSpf，改为 setAction(example.config.action) + setIpRangeType(example.config.ipRangeType) 等本模块 setter。
