系统首页 · 状态统计默认时间范围

/zh/dashboard → 系统状态面板
可用性

本次优化点

  • 问题：系统状态统计默认范围为「今日」，非工作时间（如凌晨）查看时今日数据极少，误导管理员认为系统无流量。
  • 方案：将默认范围从 'today' 改为 '24h'（最近 24 小时），确保任何时间点打开系统状态面板都能看到有意义的近期数据。

邮件处置中心 · 快速筛选 SSR 水合安全修复

/zh/email-disposal → QuickFilters 组件
SSR 修复缺陷修复

本次优化点

  • 问题：快速筛选组件在 SSR 阶段读取客户端状态（如浏览器本地存储的筛选偏好），导致 SSR HTML 与 CSR 水合后 DOM 不一致，触发 React 水合警告。
  • 方案：增加 mounted 状态 + useEffect，SSR 阶段渲染稳定的默认态，挂载后再切换到客户端真实状态，消除水合不匹配。

处置设置 · Tab 激活态样式修复

/zh/email-disposal/disposal-settings → Tab 导航栏
缺陷修复布局优化

本次优化点

  • 问题：暗色模式下，Tab 激活态背景颜色错误地显示为 bg-input/30（组件库默认值），与设计系统不符，激活态与非激活态视觉区分不明显。
  • 根因：Tailwind 生成的 CSS 中 dark:data-active:bg-background 与 dark:data-active:bg-input/30 优先级相同，后定义的组件层样式获胜。
  • 方案：改用 !（important）modifier 强制覆盖：dark:!data-active:bg-background，并统一激活态文字颜色为 text-foreground。经过 3 次迭代，最终方案稳定。
