5. 业务逻辑规格

5.1 灰邮定义与处置状态

灰邮 = 低威胁的合规批量邮件（促销/订阅/交易/社交/会员），非安全威胁，属"内容分类"维度（lib/mail-type-taxonomy 的 ContentCategory）。队列展示被灰邮策略命中并已执行处置动作的邮件，供管理员复核。

stateDiagram-v2 [*] --> Detected: 意图引擎判定=灰邮 Detected --> Archived: action=archive(归档灰色文件夹) Detected --> Marked: action=mark(标题标记[灰邮]) Detected --> Quarantined: action=quarantine Archived --> Delivered: 管理员放行 Marked --> Delivered: 管理员放行 Detected --> Deleted: 管理员删除 Delivered --> [*] Deleted --> [*]
