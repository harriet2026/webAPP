功能概述

ℹ️
背景与目标：海外邮件检测基于 IP 地理位置（GeoIP）判断邮件来源是否为境外 IP，对匹配的连接层会话执行隔离、审核、阻断或丢弃动作，用于拦截来自特定地区的潜在威胁邮件，同时允许企业维护一套自定义 IP 定位库（优先级高于系统内置 GeoIP 库）以精确匹配私有地址或特殊情况。

核心业务数据流：连接层会话到达 → 提取发件方 IP → 查自定义 GeoIP 库（有则优先）→ 查系统内置 GeoIP 库 → 判断是否命中海外 IP 且对应方向已启用 → 执行配置的动作（隔离/审核/阻断/丢弃）。

业务逻辑规格

方向 Switch 联动逻辑

条件触发行为
inbound.enabled 从 false → true收件行背景色从灰色变白；Select disabled 解除；effectPreview 从「跳过」变「命中时执行…」
inbound.enabled 从 true → false收件行背景色变灰；Select 变 disabled；effectPreview 变斜体「跳过」文案
internal.enabled 从 false → true域内行激活；同时条件渲染 amber 警告条「RFC1918私网地址…」
internal.enabled 从 true → false域内行禁用；amber 警告条消失
三方向全部 disabled显示 blue 信息条「模块处于禁用状态…建议去 Pipeline 关闭模块」；amber 警告条同时消失

GeoIP 规则优先级

demo 源码注释及 amber 信息条明确：自定义 IP 定位库 > 系统内置 GeoIP 库。命中自定义规则后直接使用对应 regionCode，不再查系统库。

编辑时 IP 字段禁用

当 editingGeoIp 非 null（编辑模式）时，IP地址/段 Input 设置 disabled={!!editingGeoIp}，因为 IP/CIDR 为规则唯一键，不允许修改（需先删除再新增）。

归属地自动填充逻辑

地区代码 Select 选中后，若 geoFormRegionDirty === false（用户未手动修改过归属地），则按 i18n key（connection.countryCN 等）自动填充归属地。一旦用户手动修改，regionDirty 置 true，后续地区代码切换不再覆盖。
