区块 / 字段规格（浏览器实测 + 源码）
基础信息 · 数据源名称*placeholder「如 总部 AD」；校验：空→「数据源名称不能为空」，>64 字→「不能超过 64 个字符」，重名→「数据源名称已存在」（实时，输入即验）
基础信息 · 同步方式*Select：LDAP / Coremail API / 网易企邮 API / CSV 导入（SYNC_TYPE_LABEL）；切换即整体替换「连接参数」区块并重置测试状态
基础信息 · 优先级number 输入，默认 50；hint「数值越大优先级越高，冲突时高优先级覆盖低优先级」
连接参数 · LDAP服务器地址*（placeholder「如 ldap.corp.com」，仅非空校验）/ 端口*（默认 389，1-65535）/ Base DN*（「如 dc=corp,dc=com」）/ Bind DN*（「如 cn=admin,dc=corp,dc=com」）/ 绑定密码*（password，新增 placeholder「请输入密码」）
连接参数 · Coremail API接口 URL*（「https://api.coremail.cn」，须 http(s) 开头）/ 管理账号*（「如 admin」）/ 账号密码*
连接参数 · 网易企邮 API接口 URL*（「https://api.qiye.163.com」）/ 企业域名*（「如 corp.cn」）/ 应用 ID*（「如 app-8821」）/ 授权码*（password）/ OpenID*（「如 open-3391」）
连接参数 · CSV 导入组织 ID*（「如 RD-001」）/ 组织名称*（「如 研发中心」）/ 上传文件（file input，accept=.csv）+ hint「支持部门与用户两个 CSV 文件，单文件不超过 50MB，需完成列映射」——列映射 UI 缺失，§9-D9
测试连接行CSV 类型不渲染；其余类型：outline 小按钮「测试连接」（有校验错误或 loading 时 disabled）+ TestResultTag（详见层级 3）
同步策略「开启自动同步」+ 说明「开启后按 Cron 周期自动拉取远端数据」+ Switch（默认关）——无 Cron/模式/冲突策略字段，§9-D4
底部「取消」outline / 「确定」蓝色主按钮；确定前置校验：有错误→toast「请修正表单中的校验错误」；非 CSV 且测试未通过→toast「请先完成连接测试并通过」；通过→toast「数据源已新增」+ 关闭 + 新行置顶（unshift）
