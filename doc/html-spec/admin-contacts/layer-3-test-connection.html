交互层级 3：测试连接（loading / 成功 / 失败 / 保存阻断）

所属组件2.2 数据源管理 Tab → 层级2 抽屉内
触发路径抽屉内填齐必填项（测试按钮解禁）→ 点击「测试连接」
状态机idle → loading(1.2s，按钮文案「测试中…」+ 灰字标签) → ok「连通正常」(绿) / fail「连接失败：超时」(红)；任一输入变更回 idle

预览可操作：本面板为 demo「Coremail API 已填齐」状态快照（名称=测试邮件系统，URL/账号/密码已填）。点「测试连接」跑完整状态机 —— demo 为 1.2s 后随机 70% 成功；预览确定性交替出 成功→失败→成功…，便于两种结果都能复核。测试未通过时点「确定」→ toast「请先完成连接测试并通过」（demo 实测）。
