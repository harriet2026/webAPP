5. 业务逻辑与指标口径

5.1 计算公式（B篇 Tooltip 是唯一来源）

  • 拦截率 = (隔离 + 阻断 + 丢弃) / 过滤总量　·　低于 95% 建议检查策略规则
  • 召回率 = 成功召回量 / 发起召回量　·　仅统计已完结的召回任务
  • 待审邮件积压 = 当前处于高级审核状态的邮件数　·　>50 建议增派人力
  • 环比 = 当日拦截率 − 前一日拦截率（红涨绿跌）
  • 地理拦截率进度条：≥97% 绿 / ≥95% 黄 / <95% 红（PRD 中唯一给了明确阈值的地方）
