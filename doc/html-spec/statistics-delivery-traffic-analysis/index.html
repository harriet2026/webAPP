#问题背景
Q1队列健康阈值取 100 还是 50？PRD §4.3 与 TC-012 自相矛盾
Q2PRD 的三角色（只读用户/运营人员/管理员）如何映射网关 RBAC？网关只有 system_admin / tenant_admin；「队列操作」权限网关侧也没有对应能力
Q3多租户口径以谁为准？PRD 没提多租户，但 demo 有租户选择器、网关 API 也支持租户隔离
Q4「生成报告」（PDF）要不要做？网关有 export.csv 与 ai-analysis，没有 PDF 端点
Q5失败口径是否包含 reject？PRD 枚举里没有 reject，但明细表「失败」列口径里有
Q6时间范围要不要支持自定义起止日期（含 90 天上限校验）？demo 只有固定枚举下拉；安全总览页却有自定义日期
