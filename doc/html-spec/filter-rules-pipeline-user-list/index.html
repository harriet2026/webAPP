4. 数据模型与 API 映射

interface UserListRule {
  id: string                 // 规则ID：UB-YYYYMMDD-NNN（黑）/ UW-YYYYMMDD-NNN（白）
  sender: string             // 发信人：精确邮箱或通配符 *@domain.com
  recipient: string          // 收信人：精确邮箱或通配符 *@dept.company.com
  action: "block" | "quarantine" | "whitelist"   // 阻断 / 隔离 / 放行
  createdAt: string
  modifiedAt: string
  enabled: boolean
  createdBy: string          // demo 扩展字段，PRD 表格未定义
}
PRD API / 数据表用途落地映射建议需确认
