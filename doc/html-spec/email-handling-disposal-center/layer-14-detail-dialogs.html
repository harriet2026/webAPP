差异标注：源码 vs 实测渲染

#项源码实测 / 落地含义
1加黑「生效范围」与加白共用 state加白 radio 的 checked 也绑定 blacklistScope（第 1352–1353 行），并非独立 whitelistScope两弹窗范围选择互相串值；落地时应拆为独立字段
2加黑 checkbox 状态未参与提交includeSubdomains 有 state，但确认仅 handleAction("blacklist")（sleep 1s），未读取该值demo 桩实现；落地需把「含子域」→ 规则匹配模式
3「更多」6 项全部未实现moreActions 每项 onClick 均为 console.log(...)（第 551–557 行）导出EML/PDF、标记误报/漏报、加入调查任务均为占位
4投递/丢弃描述有双分支有 selectedRecipientData → 「投递给 {email}」；否则退化为隔离区通用文案（第 1370–1376 / 1400–1406 行）抽屉内恒有选中收件人，实测总走前一分支
5批量结果仅详情抽屉有handleBatchAction 产出 batchResults 部分成功汇总（第 439–485 行）列表页批量处置无此「操作完成」汇总弹窗

注：预览为无 radix runtime 的静态 DOM 重建；弹窗定位由 fixed 改为静态内联居中以适配规格页（内容/class 未改）。交互（开关/勾选/关闭/确认 toast/菜单展开）由本页内联脚本复刻，均非空 onclick。
