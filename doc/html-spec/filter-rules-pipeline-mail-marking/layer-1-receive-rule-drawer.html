基础配置优先级 number Input5（=当前 Tab 规则数 4 + 1）；min=1非法输入回退 1；允许重复右侧常显括号说明「数字越小优先级越高…」。
基础配置状态 RadioGroup启用-禁用/启用两项；对应规则行 opacity 与 Badge。
适用对象适用部门 Select + Badge空（=全部用户）；placeholder「选择部门...」-选中追加 secondary Badge（带 X 可移除），下拉隐藏已选项；标题旁小字「(收信人维度)」。
适用对象适用群组 Select + Badge空；placeholder「选择群组...」；选项 全体员工/外包人员/全体管理层/海外办事处-同部门；底部 Info 常显「不选任何部门/群组 = 适用于全部用户」。
标记配置标记文案 Input【外站邮件】（新建预填）；maxLength=50必填；空值红字「请输入标记文本」下方 4 个变量 Badge：{sender_domain} {sender_ip} {recipient_name} {date}，点击追加「 {var}」。
标记配置标记位置 RadioGroup主题前缀-主题前缀 / 正文顶部 / 邮件头标记 / 多位置同时生效（=主题前缀+正文顶部同时生效）。
标记配置标记样式 RadioGroup蓝色标签-蓝色标签 / 橙色警告 / 纯文本 / 自定义配色；选自定义展开配色面板。
标记配置自定义配色面板背景 #FFF3E0、文字 #E65100、边框 #FF9800、圆角 4px（0-20）color 控件限制格式；hex 文本未校验仅 markStyle=custom 渲染；四参实时映射预览 inline style。
