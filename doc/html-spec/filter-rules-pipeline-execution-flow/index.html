2.3 统一阶段抽屉框架 UnifiedStageDrawer ★（v2 新增）

「统一框架，不同模块有不同信息」：阶段1/2/3/5 的每张策略卡片点击后，均打开一个结构一致的 w-[80vw] 右滑 Sheet。外壳（面包屑头 + 关闭 + 左侧模块导航 + 右侧模块内容 + 折叠柄）在 4 个阶段完全相同；差异只在：① 面包屑阶段名；② 左侧模块列表（各带专属副标题摘要）；③ 右侧内容（各模块自有的表格/表单/Tab）。抽屉内嵌各阶段完整策略页（<XxxStrategyPage embedded initialPolicy=... />）。
demo 位置外壳 strategy-pipeline-page.tsx:2007-2193（4 个 Sheet）；内容 connection-layer-page.tsx / identity-strategy-page.tsx / content-strategy-page.tsx / comprehensive-strategy-page.tsx（均 embedded）
状态管理fullPageDrawerOpen/Policy、identityDrawerOpen/Policy、contentDrawerOpen/Policy、comprehensiveDrawerOpen/Policy（4 组独立 state）
交互层级数3 层（层级0 抽屉外壳打开=本文件内嵌；层级1·2 IP 模块切换=子文件；层级3 跨阶段变体=子文件）
拆分策略层级 0 内嵌；层级1·2 → layer-1-drawer-ip-modules.html；层级 3 → layer-2-stage-variants.html
