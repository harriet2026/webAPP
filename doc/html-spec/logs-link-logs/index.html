5. 业务逻辑：顺序检测模型

1. 云端情报        —— 查询云端威胁情报库
2. 本地黑名单      —— 匹配本地 URL 黑名单规则
3. URL沙箱 / 钓鱼邮件智能体 —— 二次深度检测（AI 版=钓鱼智能体，传统版=URL沙箱）

任一环节命中即告警并停止后续检测（命中即停）
triggerStage 记录首个命中环节；三段均未命中 → none（安全放行）

⚠ PRD 内部矛盾：主 PRD / 0704 是「云端情报 → 本地黑名单 → 深度检测」，而 0709「点击时复检策略」写的是「回扫黑名单 → 查询情报 → 深度复检」（前两环节顺序相反）。demo 按主 PRD 渲染时间线 → §10 Q1。

5.1 权限与形态矩阵（PRD）

形态可见性租户范围筛选数据范围
云网关✅✅ 显示全平台，可按租户筛选
AI 多租户✅❌全平台
AI 单租户✅❌全部
传统多租户 / 传统单租户❌ 整模块隐藏（能力位 = ai）——
租户管理员（多租户）✅❌仅本租户

⚠ demo 的 lib/product-profiles.ts 把 link-logs 标为 capability: "base" + visibility: ALL_SHOW —— 与 PRD 的「能力位 ai + 传统版隐藏」直接冲突（同目录的 ai-url-logs 用的是 LEGACY_HIDE_AI，方向还相反）→ §10 Q2。

10. 需确认事项

#问题背景
Q1顺序检测的前两环节到底是「云端情报 → 本地黑名单」还是「回扫黑名单 → 查询情报」？主 PRD/0704 与 0709 互相矛盾；这直接决定 triggerStage 的语义与时间线渲染顺序
Q2本模块能力位是 ai（传统版隐藏）还是 base（全形态可见）？PRD 说 ai + 传统版 ❌ 隐藏；demo 的 product-profiles 说 base + ALL_SHOW
Q3「跳过深度检测」态的 UI 细节？0709 只说「橙色标签」；筛选下拉的选项文案、详情弹窗里如何呈现（时间线里算命中还是跳过？）未定义
Q4「下载」导出的是什么格式、含哪些字段？PRD 只说「单条留证导出」；网关 /:id/download 已实现，需对齐格式
Q5列表要不要加「所属租户」列？平台视角可按租户筛选，但列表没有租户列，筛选后看不出每行归属（认证日志同样问题）
Q6时间范围筛选？PRD 只有「点击时间」单日期；网关 API 是 start/end 区间
