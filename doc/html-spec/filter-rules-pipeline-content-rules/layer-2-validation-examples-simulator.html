所属组件2.3 内容规则编辑抽屉 RuleEditDrawer（右侧折叠区 + 表单校验态）
触发路径层级2 抽屉内：点击「保存」（空表单）→ 校验红字；类型切正则 + 输入非法正则 → 实时错误；点击「查看配置示例」→ 展开三张示例卡；点击「模拟测试」→ 展开测试区并执行
校验规则（源码 validateForm）name 非空 && matchContent 非空 && scopes ≥1 && (regex 时无语法错误) && 至少一个方向启用；不通过则 setShowErrors(true)，抽屉保持打开。showErrors 打开后错误随输入实时消隐。
浏览器实测空表单点保存显示：「请输入规则名称」「请输入匹配内容」（方向/作用域有默认值故不报）；输入 [0-9 显示「正则表达式语法错误，请检查」+ textarea 红框（aria-invalid 样式 border-destructive）；应用示例1后表单变为 regex/\d{17}[\dXx]/正文+附件内容/阻断+告警，但正则错误红字残留（demo 缺陷，主文件 D3）；模拟测试命中→红底、未命中→绿底。

银行卡号检测

检测16-19位银行卡号
当邮件正文包含16-19位数字（疑似银行卡号）时，进入审核队列。

敏感词过滤

过滤敏感内容
当邮件主题或正文包含敏感词时，所有方向均阻断。
