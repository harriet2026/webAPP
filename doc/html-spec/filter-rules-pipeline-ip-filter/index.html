1. 页面布局结构

1.1 入口与区域划分

IP黑白名单功能以两种模式呈现：

  • 流水线嵌入模式：在 /filter-rules/pipeline 页面点击"IP黑白名单"策略卡片，打开 80vw 右侧抽屉（Sheet），抽屉内嵌 ConnectionLayerPage 组件。
  • 独立全页模式：直接访问 /filter-rules/connection，全页展示 ConnectionLayerPage，左侧导航四个 IP 策略（IP频率限制/IP黑白名单/RBL过滤/海外邮件检测），右侧配置区。
