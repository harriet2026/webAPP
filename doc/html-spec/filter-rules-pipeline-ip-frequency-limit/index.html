编写标记

[Base]功能基线：模块的规则 CRUD、批量删除、批量导入/导出、挂起IP管理等核心交互，在所有「可见」的形态×角色下行为一致（不随 AI 能力变化，capability=base，传统版同样可用）。
[多租户差异：租户视角]多租户形态（云-多/AI-多/传统-多）的租户管理员视角下，IP频率限制入口隐藏——IP策略相关配置收归平台侧安全策略，租户不暴露。
[单租户]单租户形态（AI-单/传统-单）无平台/租户分层，IP频率限制对管理员照常可见可编辑。
