4.2 失败原因 → 处置建议（7 类，详情页「失败诊断」展示）

key失败原因处置建议
wrongPassword密码错误短时间内多次密码错误可能为撞库 / 暴力破解，建议核查账号是否泄露并启用登录限速
userNotExist账号不存在常见于扫描探测，建议关注来源 IP 是否存在批量尝试
accountLocked账号锁定确认是否为多次失败触发的安全策略，必要时人工解锁
serverTimeout服务器超时检查认证服务器负载与网络链路，或适当调大认证超时时间
connectionRefused连接拒绝检查认证服务器端口可达性与防火墙策略
certError证书错误检查服务器证书是否过期、链路是否被中间人篡改
protocolMismatch协议不匹配确认客户端协议与该域名认证配置一致
