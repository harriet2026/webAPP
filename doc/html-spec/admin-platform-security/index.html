5.3 基线下沉与关联关系（PRD 唯一事实源）

  • 多租户下，IP 策略与附件基础限制的配置权由平台管理员经本模块独占，统一下沉至所有租户；租户管理员在模块A中 IP 阶段呈锁定只读（I 区占位）。
  • 单条基线修改即时影响所有租户，不针对个别租户；基线更新后各租户下次匹配即生效（最终一致，PRD §4.4）。
  • 邮件匹配时先加载 scope=platform 基线（阶段1及附件基础），再叠加当前 tenant_id 的租户策略（PRD §6.1）。
  • 附件基础限制为平台级资源约束，租户侧「附件安全检测」不含此项（页面提示条明示）。
