5. 业务逻辑

模块背景（spec/URL检测与防护模块 - 需求文档.md）：URL 沙箱在投递前对邮件中的未知 URL 做动态行为分析（区别于链接保护日志的「用户点击时」检测）。本页即沙箱分析结果的审计视图。AI 版 PRD（钓鱼邮件智能体 / V2）要求在检测日志的 URL 下钻中「复用 AI-URL 沙箱日志弹窗」—— 即本页 §3.1 弹窗是跨模块共享组件。
