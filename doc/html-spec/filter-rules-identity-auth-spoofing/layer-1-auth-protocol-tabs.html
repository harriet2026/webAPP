标准模式

DMARC检查配置

标准模式
p=reject
发信域要求拒绝未通过验证的邮件
p=quarantine
发信域要求隔离未通过验证的邮件
p=none
发信域仅监控，不要求处置

DMARC验证依赖SPF或DKIM对齐结果。如果SPF和DKIM均被禁用，DMARC验证将始终失败。

PTR反向解析配置

标准模式
记录不存在
发信IP无PTR反向解析记录
查询失败
PTR DNS查询超时或失败
与EHLO不匹配
PTR记录与SMTP EHLO/HELO不一致
与A记录不匹配
PTR反查的A记录不指向原IP

PTR检查在连接层执行，但在此处统一配置策略。

本层差异说明

Radix Tabs 在 demo 中卸载非激活面板（hidden 且无子节点）。若照搬该 DOM，spec 内的 Tab 将点不动。因此本 spec 把 DKIM/DMARC/PTR 三个面板在其各自激活时抓取的真实 DOM 内嵌回来，并标记 hidden。除挂载状态外，节点结构与 demo 逐节点一致。
