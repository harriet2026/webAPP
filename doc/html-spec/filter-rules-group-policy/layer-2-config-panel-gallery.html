每个配置卡都不一样：逐卡确认

⚠ 中栏共 14 个可配置策略卡（名单/基础设施类强制项折叠为「全局统一管控」不在此列）。每个卡的配置面板都不同：① 全局默认配置参照卡内容各异（PolicyGlobalReference 按 policyKey 渲染）；② 策略状态档数不同——有 hasParams/hasSubPolicies 的卡为 4 档（含「自定义参数/自定义子检查」），其余为 3 档；③ 部分卡有专属特殊体（附件 4 Tab / 认证子检查 / 海外禁用→豁免原因 / 意图引擎禁用→高风险警告）。下方按阶段逐卡给出「截图 + 可交互面板 + DOM 比对」。
