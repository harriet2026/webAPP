群组策略规则

针对特定群组（IP组/发信人组/收信人组）配置策略的启用/豁免/强制，实现基于对象维度的策略管控

模块的执行顺序由阶段流水线（阶段1→阶段5）固定决定，与优先级无关；优先级（0000-0099）仅在多条策略命中同一封邮件、且配置了同一模块时用于仲裁——数值越小越优先生效。
