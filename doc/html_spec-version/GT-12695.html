移除所有「使用该示例」回调中的 list_type 硬编码赋值全部移除，填充字段仅含 sender_config / ip_range / action / priority
影响文件SenderFilterDrawer.tsx（CollapsibleContent 示例区块）

1.1 截图式交互预览

维度说明
