三、变更概览

编号变更位置变更内容类型
1智能体调查与处置卡片修正运行模式说明中的异常字符，统一为“运行模式决定是否执行处置，防护等级与置信度分级决定处置方式；超时策略对所有旁路检测生效”。文案优化
2运行模式配置抽屉覆盖实时检测、观察模式、观察期间追加标记、超时临时处置、标记前缀和高级设置等配置区域，保持现有配置项、状态联动和保存行为不变。配置体验记录
3置信度分级处置表格新增风险等级徽章列，按置信度区间从低到高自动派生“可疑、低危、中危、高危”，采用中性、蓝色、橙色、红色的语义色阶。信息层级优化
4置信度区间编辑器扩大置信度区间列和数字输入框宽度，输入框使用固定宽度、内边距、居中对齐和等宽数字，确保 0 至 100 范围内的数字完整显示。可用性优化
5准入规则抽屉记录检测范围、方向、特定收发信人筛选、风险信号和启用规则等现有配置入口，作为检测引擎配置模块的关联界面范围。规格补全

四、已落地优化说明

4.1 置信度数字完整显示
  • 区间列最小宽度由 128px 调整为 160px。
  • 区间输入框宽度由 56px 调整为 64px，并设置为不收缩。
  • 输入框增加水平内边距、文本居中和 tabular-nums 等宽数字样式。
  • 区间两端使用更宽间距，避免输入值、分隔符和容器边界相互挤压。
4.2 兼容性边界
  • 不修改置信度区间数据结构、校验规则、接口调用和保存逻辑。
  • 不新增字段、不删除字段、不改变处置动作选项。
  • 仅调整显示空间和输入框样式，窄屏场景沿用表格横向滚动能力。

五、界面状态与交互范围

界面状态规格记录
检测引擎配置页展示检测总览与检测引擎配置两个页签，配置页包含检测范围与准入规则、智能体调查与处置两张核心卡片。
运行模式配置实时检测与观察模式互斥选择；实时检测展示超时处理与置信度分级处置；观察模式展示观察期间追加标记，禁用实际隔离、审核和召回等处置动作。
置信度分级处置表格列为置信度区间、风险等级、处置动作和标记设置。风险等级仅用于展示，不新增可编辑字段，按四档区间的置信度排序自动派生。
准入规则抽屉支持规则名称、方向、特定收发信人筛选、部门树、风险信号和启用规则等检测范围配置；保存与取消操作固定在抽屉底部。

七、验收标准

  • 智能体调查与处置说明语义完整，不包含异常字符或乱码。
  • 运行模式配置可清晰区分实时检测和观察模式，状态提示与可用配置保持一致。
  • 置信度分级表格显示风险等级“可疑、低危、中危、高危”，且等级顺序与置信度区间从低到高一致。
  • 置信度区间输入框内的两位数和三位数完整可见，不出现裁切。
  • 四组区间的起始值、结束值和中间分隔符保持清晰可辨。
  • 输入、校验、保存和处置动作选择行为与优化前一致。
  • 准入规则抽屉的检测范围与风险信号配置入口保持可用。
