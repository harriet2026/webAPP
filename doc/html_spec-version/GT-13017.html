GT-12888 内容规则-列表未展示优先级且新建规则难以定位问题解决

1. 问题与目标

内容规则列表此前缺少优先级信息，用户在新建规则后难以通过列表定位并核对规则执行顺序。本需求在列表中补充优先级展示，并保持既有列表功能不变。

2. 最终实现方案

项目实现内容事实源
新增列新增“优先级”列，读取规则数据中的 priority 字段。ContentRulesTable.tsx
列顺序“优先级”放在“状态”字段之前。用户要求与页面截图
国际化列标题读取 contentRules.priority，不硬编码中文文案。项目 i18n 框架
范围控制不修改新建规则流程、保存接口、分页、筛选、操作列及其他模块。需求范围约束

GT-13027 内容规则：保存/取消按钮从右上角移动到右下角，同时去掉右上角的“关闭x”按钮

1. 问题与目标

内容规则新建/编辑抽屉的保存、取消操作位于标题区右上角，且右上角同时存在通用关闭入口。需求目标是参考发信人黑白名单规则的新建/编辑页面，将操作区统一调整为抽屉底部右侧，并移除右上角关闭 X 按钮。

2. 最终实现方案

项目实现内容事实源
标题区仅保留新建/编辑标题与说明文案，不显示保存、取消按钮。ContentRuleDrawer.tsx
关闭入口关闭 SheetContent 的通用右上角关闭按钮。showCloseButton={false}
底部操作栏在抽屉底部增加独立操作栏，按钮右对齐，顺序为“取消”在左、“保存”在右。用户提供截图与参考页面
国际化继续使用 common.cancel 与 common.save，不硬编码中文文案。项目国际化框架
业务逻辑保留既有保存、取消事件、表单校验、提交状态和接口逻辑。范围约束
