3. 变更概述与根因

问题描述

全局侧边栏底部额外显示开发构建版本信息（例：「版本 c70d71c+dirty」），该内容与 component-sidebar-nav html_spec（active 状态）不符。规格定义侧边栏只包含 Logo 区和导航区域，未定义版本脚注。

2026-07-28 QC 环境复查记录

项目值
复查日期2026-07-28（只读，真实浏览器）
复查路由/zh/dashboard
app-version-footer 数量1
显示文本版本 c70d71c+dirty
悬停 title 属性rev=c70d71c970e0b6b63fc26985a5767a9b29916f10+dirty built=… build_tag=opengauss
根因确认SidebarNav 无条件挂载 VersionFooter；VersionFooter 请求 /version 后显示七位 commit，modified=true 时追加 +dirty

修复方案

操作文件具体变更
移除挂载 src/components/layout/sidebar-nav.tsx 删除 JSX 中 <VersionFooter /> 一行（原第 245 行）
移除 import src/components/layout/sidebar-nav.tsx 删除 import { VersionFooter } from './version-footer'（原第 15 行）
保留组件 src/components/layout/version-footer.tsx 文件本身不删除，供 GT-11459 能力在产品确认入口后复用
