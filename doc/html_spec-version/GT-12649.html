GT-12655 多租户租户管理员视角处置依据"平台管控策略"显示方案

组件：mail-list-table.tsx · threat-summary-card.tsx · analysis-section.tsx · quick-filters.tsx · 路由：/zh/email-disposal/center · 变更类型：功能变更 · 2026-07-30
背景：在云网关 / AI 版多租户 / 传统版多租户产品形态下，登录视角切换为租户管理员时，阶段1（连接层）策略为平台级策略，租户无权查看或配置具体规则。因此所有涉及"处置依据"的展示点，若触发策略为阶段1，需将具体策略信息模糊化，统一展示为"平台管控策略"，引导用户联系平台管理员。

方案概述

触发条件说明
产品形态 云网关-多租户 / AI版-多租户 / 传统版-多租户（capabilities.multiTenant === true）
登录视角 租户管理员（viewer === 'tenant'）
处置依据策略 阶段1（连接层）策略：IPFREQ / IPBL / RBL / OVERSEAS（isStage1Policy(policy_key) === true）
不触发条件 单租户形态；平台管理员视角；阶段2~5 策略
