# Markdown Spec 静态模板参考

本模板供 `md-spec-generator` 生成只读 Markdown 规格。它保留交互预览，但所有交互预览都由真实 webapp 的状态截图序列和对应信息组成，不包含业务组件标签/JSX、模拟交互控件或 mock 状态机。

使用时替换 `<...>` 占位符，并按实际模块增删章节。不要加入 Tailwind、从 webapp 提取的 `outerHTML`/JSX、表单控件标签、事件绑定或 JavaScript。除本文件规定的锚点标记 `<a id="...">` 外，不使用任何原生 HTML 标签。

## 模块主文件模板（`index.md`）

```markdown
# <页面名称> 规格说明

| 字段 | 内容 |
|---|---|

| 生成日期 | <YYYY-MM-DD> |
| 页面路由 | `<zh/route>` |
| webapp 源码 | `<webapp/src/...>` |
| webapp commit | `<short-hash>` |
| 需求依据 | 用户当前描述 + 可获得的历史决定 + webapp 当前运行态 |
```

## 模板检查清单

- 每条关键交互有真实的触发前/后截图序列、触发路径、对应元素和结果信息。
- 交互预览用标题 + 状态信息表格 + `![]()` 截图 + 斜体说明 + 元素表格呈现，不使用轮播、折叠或热点点击。
- 页面没有提取的 `outerHTML`/JSX、业务表单控件描述、事件绑定或模拟操作伪代码。
- 页面不引用 Tailwind CDN 或任何前端框架资源。
- 除锚点标记 `<a id="...">` 外，页面不包含任何其他原生 HTML 标签，不包含 `<script>`。
- 截图和内部链接使用相对路径。
- 形态/角色矩阵、差异、待确认、版本历史齐全。
- 离线打开（纯文本/Markdown 阅读器）时仍可阅读全部核心信息。
- 目录锚点在实际渲染环境（GitHub、IDE 预览等）中逐条验证可跳转。
