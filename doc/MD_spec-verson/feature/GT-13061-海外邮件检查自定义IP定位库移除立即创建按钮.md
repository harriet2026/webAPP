# GT-13061 海外邮件检查：自定义 IP 定位库空状态移除“立即创建”按钮

## 1. 需求背景

海外邮件检查页面的“自定义 IP 定位库”在没有数据时，空状态区域不应重复提供“立即创建”入口。页面保留统一工具栏中的“新增规则”作为创建入口，避免空状态操作重复。

## 2. 功能路径

安全策略模块 → 海外邮件检查 → 自定义 IP 定位库。

## 3. 用户问题

当自定义 IP 定位库没有数据时，空状态说明下方额外显示“立即创建”按钮。该按钮与页面顶部“新增规则”功能重复，需移除。

## 4. 最终方案

- 移除空状态区域中的“立即创建”按钮。
- 保留空状态图标和“暂无自定义IP规则，系统将使用内置GeoIP库进行地域识别”说明。
- 保留页面顶部“新增规则”按钮。
- 保留搜索、重置、导入、导出及已有规则的编辑、删除等功能。
- 继续使用项目现有国际化框架，不新增硬编码文案。
- 不修改接口、权限、数据结构、规则逻辑或其他功能模块。
