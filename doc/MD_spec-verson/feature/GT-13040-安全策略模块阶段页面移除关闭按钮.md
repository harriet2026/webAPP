# GT-13040 安全策略模块：阶段1至阶段5页面移除关闭 X 按钮

## 1. 需求概述

安全策略模块阶段1、阶段2、阶段3、阶段4、阶段5及其页面内部二级弹窗均存在右上角关闭 X 按钮。统一移除这些关闭入口，保持页面既有底部操作、取消、保存、确认及业务关闭逻辑不变。

## 2. 优化范围

- 阶段1至阶段5统一配置主抽屉。
- 阶段页面内部的 Sheet、Dialog、Drawer 等二级弹窗。
- 群组策略配置详情面板等自定义关闭入口。
- 不修改接口、权限、表单校验、数据模型、业务逻辑或其他非安全策略模块。

## 3. 实现规则

| 项目 | 规则 |
| --- | --- |
| 默认关闭入口 | 安全策略范围内的 Sheet/Dialog/Drawer 使用 `showCloseButton={false}`。 |
| 自定义关闭入口 | 移除标题栏或详情面板中的关闭 X 自定义按钮。 |
| 操作出口 | 保留项目现有取消、保存、确认按钮和业务关闭逻辑。 |
| 国际化 | 继续使用项目现有国际化框架，不新增硬编码中文按钮文案。 |
| 编码 | 中文文件与页面文案使用 UTF-8，禁止 replacement character（U+FFFD）。 |

## 4. 页面与组件范围

| 页面或功能 | 调整内容 |
| --- | --- |
| 阶段1至阶段5统一配置页面 | 移除主配置抽屉右上角关闭 X。 |
| IP 频率限制、IP 黑白名单、RBL 过滤 | 移除页面内部二级弹窗的默认关闭 X。 |
| 发信人黑白名单、邮件标记、内容规则 | 移除抽屉右上角默认关闭 X。 |
| 行为管控、意图引擎 | 移除相关 Drawer/Dialog 的默认关闭 X。 |
| 群组管理、群组策略、高级规则 | 移除二级弹窗、详情面板中的关闭 X。 |
| 认证探测与统计、IP 导入、地理库 | 移除相关 Dialog/Sheet 的默认关闭 X。 |
