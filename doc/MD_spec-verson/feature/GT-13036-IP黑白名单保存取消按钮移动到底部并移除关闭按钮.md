# GT-13036

## 需求名称

IP黑白名单：保存/取消按钮从右上角移动到右下角，同时去掉右上角的“关闭x”按钮

## 一、问题背景

IP黑白名单新建/编辑页面的保存、取消操作原位于抽屉右上角，且右上角存在通用关闭入口。用户需要与同类规则页面保持一致，将主要操作统一放置在抽屉底部右侧，并移除右上角关闭按钮。

## 二、需求目标

- 将保存、取消按钮从右上角移动至页面右下角。
- 移除右上角通用关闭 X 按钮。
- 保留既有表单校验、保存、取消、权限和接口行为。
- 使用项目现有国际化框架，不在组件中硬编码中文文案。

## 三、实现方案

| 项目 | 方案 | 事实源 |
| --- | --- | --- |
| 标题区 | 保留新建/编辑标题及说明文案，不显示保存、取消按钮。 | `IPFilterPage.tsx` |
| 关闭入口 | 设置 `SheetContent` 的 `showCloseButton={false}`，移除右上角关闭按钮。 | `IPFilterPage.tsx` |
| 底部操作栏 | 在抽屉底部增加右对齐操作栏，取消在左、保存主操作在右。 | 用户提供截图 |
| 国际化 | 继续使用 `common.cancel` 与 `ipFilter.saveAndEnable`。 | 项目 i18n 框架 |
| 业务范围 | 不改变 IP 地址/段、动作、优先级、有效期及保存接口逻辑。 | 范围约束 |

## 四、页面与交互

触发路径：进入 IP 策略 → IP 黑白名单 → 新建或编辑规则。

验收重点：标题区右上角不显示关闭 X；保存和取消固定在抽屉底部右侧；保存按钮保持主操作样式，取消按钮保持次要描边样式；表单内容可滚动且底部操作栏保持可见。

## 五、验收标准

- 新建 IP 黑白名单页面右上角不显示关闭 X。
- 编辑 IP 黑白名单页面右上角不显示关闭 X。
- 保存、取消按钮位于抽屉底部右侧。
- 继续使用项目国际化键，不新增硬编码中文。
- 保存、取消行为与原有逻辑一致。
- 其他功能模块不受影响。

## 六、范围边界

本需求仅涉及 IP 黑白名单新建/编辑页面的操作区布局和关闭入口，不涉及 IP 频率限制、RBL 过滤、海外邮件检测或其他安全模块。
