# GT-13065 发信行为管控：空数据状态移除“立即创建”按钮并默认展示表头字段

## 1. 需求背景

发信行为管控规则列表为空时，空状态区域额外显示“立即创建”按钮，与页面顶部“新建规则”入口重复。本需求移除空状态中的重复按钮，并确保空数据状态仍默认展示完整规则列表表头。

## 2. 需求范围

- 页面：安全策略模块 → 发信行为管控。
- 空数据状态：移除“立即创建”按钮及其专属操作区域。
- 空数据状态：保留规则列表表头。
- 其他功能：保留“新建规则”、搜索、方向/类型/状态筛选、重置、导入、导出及分页能力。
- 不修改接口、权限、规则编辑、删除、启用/禁用和其他安全策略模块。

## 3. 规则列表表头

空数据状态下默认展示以下九个字段，顺序保持一致：

1. 规则ID
2. 规则名称
3. 管控方向
4. 管控对象
5. 执行动作
6. 优先级
7. 状态
8. 修改时间
9. 操作

## 4. 国际化与编码

继续使用项目现有国际化框架，复用现有字段和空状态文案翻译键，不新增硬编码页面文案。中文内容使用 UTF-8 编码，禁止 replacement character（U+FFFD）和异常全角问号。

## 5. 截图事实源

用户提供的截图显示：

- 优化前空状态中存在“立即创建”按钮。
- 优化后空状态保留完整九列表头，并移除“立即创建”按钮。

## 6. 验收标准

- [ ] 发信行为管控无数据时不显示“立即创建”按钮。
- [ ] 无数据时仍显示完整九列表头。
- [ ] 表头顺序为：规则ID、规则名称、管控方向、管控对象、执行动作、优先级、状态、修改时间、操作。
- [ ] 页面顶部“新建规则”入口保持可用。
- [ ] 搜索、筛选、重置、导入、导出及已有规则操作不受影响。
- [ ] 继续使用项目国际化框架。
- [ ] 未修改其他功能模块。

## 7. 修改范围

仅涉及发信行为管控规则列表的空状态展示：移除重复创建按钮，并保留默认表头。
