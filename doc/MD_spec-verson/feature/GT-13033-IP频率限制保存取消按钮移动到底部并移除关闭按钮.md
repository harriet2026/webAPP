# GT-13033

## 需求名称

IP频率限制：保存/取消按钮从右上角移动到右下角，同时去掉右上角的“关闭x”按钮

## 需求背景

IP频率限制新建/编辑页面原先将保存、取消操作放在右上角标题区，并显示测试按钮与通用关闭入口。为统一规则编辑页面的操作位置，保存与取消需要固定在抽屉底部右侧，同时移除右上角关闭按钮；测试按钮也不再展示。

## 目标

1. 将保存、取消按钮移动到 IP 频率限制新建/编辑抽屉底部右侧。
2. 去掉右上角通用关闭 X 按钮。
3. 去掉标题区测试按钮。
4. 保留既有保存、取消行为、校验、提交状态和接口逻辑。
5. 复用项目国际化框架，不在组件内硬编码中文文案。

## 适用范围

- 页面：IP 频率限制配置。
- 路由：`/zh/security/pipeline` → IP频率限制配置 → 新建/编辑规则。
- 组件：`src/components/security/IPFrequencyPage.tsx`。
- 角色：具备 IP 频率限制编辑权限的平台管理员、租户管理员。

## 实现要求

| 项目 | 要求 |
| --- | --- |
| 标题区 | 保留新建/编辑标题、说明文案；不显示测试、保存、取消按钮。 |
| 关闭入口 | 使用 `showCloseButton={false}` 移除右上角关闭 X。 |
| 底部操作栏 | 使用独立底部栏，按钮右对齐，顺序为“取消”在左、“保存”在右。 |
| 国际化 | 保存、取消继续使用 `common.save`、`common.cancel`。 |
| 业务逻辑 | 不修改保存、取消、校验、提交状态、接口及权限逻辑。 |
| 范围边界 | 不修改 IP 黑白名单、RBL 过滤、海外邮件检测或其他功能模块。 |
