# GT-13059

## 需求名称

IP黑白名单，发信行为管控，高级过滤规则三个模块的规则列表补充优先级字段，需要全部都去掉

## 需求背景

安全策略规则列表需要统一展示规则优先级，便于用户理解规则匹配顺序和策略执行顺序。用户提供的 IP 黑白名单和发信行为管控截图已展示优先级列，作为本需求的真实页面事实源。

## 优化范围

| 模块 | 规则列表调整 | 字段位置 |
| --- | --- | --- |
| IP 黑白名单 | 补充优先级字段 | 位于状态字段之前 |
| 发信行为管控 | 补充优先级字段 | 位于状态字段之前 |
| 高级过滤规则 | 补充优先级字段 | 位于状态字段之前 |

优先级字段使用现有规则数据中的 `priority` 值，不新增接口、不改变排序、不改变保存逻辑、不改变权限和校验逻辑。

## 展示与国际化

- 表头继续使用项目国际化框架。
- 中文表头为“优先级”。
- 英文、泰文、俄文同步提供对应翻译。
- 数据行展示当前规则的数值型 `priority`。
- 仅调整规则列表展示列，不修改其他策略模块。

## 页面事实源

截图 1：IP 黑白名单规则列表，展示“IP地址/段、操作、优先级、状态、修改时间、操作”。

截图 2：发信行为管控规则列表，展示“规则ID、规则名称、管控方向、管控对象、执行动作、优先级、状态、修改时间”。

高级过滤规则沿用同一规则列表列顺序，在状态字段前增加优先级列。
