# GT-13070 IP频率限制，IP黑白名单，发信人黑白名单，发信行为管控，内容规则，高级过滤规则，邮件标记与声明这几个模块的“规则列表”的状态字段样式保持一致

## 1. 需求背景

IP频率限制、IP黑白名单、发信人黑白名单、发信行为管控、内容规则、高级过滤规则、邮件标记与声明七个安全策略模块的规则列表均包含状态字段。优化前部分模块使用 Badge 或 StatusBadge，部分模块使用 Switch，状态列的视觉样式和交互方式不一致，用户跨模块查看规则时难以形成统一认知。

本需求统一七个模块规则列表状态字段的展示样式，以发信人黑白名单模块现有状态列为基准，使用蓝色启用、灰色停用的 Switch 形态。

## 2. 需求目标

- 统一七个模块规则列表“状态”字段的视觉表现。
- 统一启用、停用状态的交互认知：启用为蓝色 Switch，停用为灰色 Switch。
- 复用项目现有国际化框架，不在组件中新增硬编码中文文案。
- 保留各模块现有权限、接口和业务状态语义，不扩展无明确产品要求的编辑能力。

## 3. 最终实现方案

### 3.1 统一状态字段规范

- 状态列统一使用项目现有 `Switch` 组件。
- `checked` 绑定规则当前启用状态。
- 启用状态显示蓝色 Switch，停用状态显示灰色 Switch。
- `aria-label` 使用项目国际化框架中的启用/停用文案键。
- 可交互模块点击 Switch 后调用现有状态更新能力，更新失败时保留现有错误处理并恢复原状态。

### 3.2 七个模块的落地规则

| 模块 | 状态列方案 | 交互与特殊状态 |
| --- | --- | --- |
| IP频率限制 | Switch | 正常规则可切换；已过期规则 Switch 禁用，并保留过期辅助提示。 |
| IP黑白名单 | 只读 Switch | 保持原有仅支持新建、删除的产品约束，Switch 仅统一视觉形态，不新增启停能力。 |
| 发信人黑白名单 | Switch | 作为统一样式基准，支持直接切换启用/停用。 |
| 发信行为管控 | Switch | 接入已有启停接口，状态列作为直接操作入口。 |
| 内容规则 | Switch | 正常规则可切换；即将过期、已过期状态通过辅助提示保留语义，已过期规则不可切换。 |
| 高级过滤规则 | Switch | 使用已有启停能力，移除操作列中重复的启用/停用文字按钮。 |
| 邮件标记与声明 | Switch | 复用现有规则保存接口进行 `is_active` 局部更新。 |

### 3.3 国际化与编码

- 所有状态标签、辅助提示和可访问性文案使用项目既有国际化键。
- 中文内容使用 UTF-8 编码。
- 不使用 Unicode replacement character，不引入异常全角问号字符。

## 7. 变更范围

本需求仅覆盖七个安全策略模块规则列表的状态字段样式、对应状态切换接线和必要的国际化文案使用。除高级过滤规则重复启停入口移除、过期规则的禁用提示以及邮件标记与声明的状态局部保存外，不改变规则创建、编辑、删除、筛选、分页、导入导出、权限和其他业务逻辑。
