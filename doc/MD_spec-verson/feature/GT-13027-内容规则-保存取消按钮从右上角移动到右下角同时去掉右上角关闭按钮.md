# GT-13027
# 内容规则：保存/取消按钮从右上角移动到右下角，同时去掉右上角的“关闭x”按钮

- **文档类型**：增量需求文档
- **关联总工单**：GT-13017【0818】处理问题总工单
- **页面范围**：阶段3：内容层 / 内容规则
- **页面路由**：`/zh/security/content-rules`
- **实现文件**：`src/components/security/content-rules/ContentRuleDrawer.tsx`
- **生成日期**：2026-08-18

## 1. 问题背景

内容规则新建/编辑抽屉的保存、取消操作位于标题区右上角，与表单内容的阅读和提交路径不一致；右上角同时存在通用关闭入口，造成多个退出操作入口，增加误操作和认知负担。

## 2. 需求目标

参考“发信人黑白名单”规则的新建/编辑页面，将内容规则抽屉的操作区统一调整为底部右侧操作栏：保存与取消按钮固定在右下角，并移除右上角关闭 X 按钮。

## 3. 最终方案

1. 标题区仅保留新建/编辑标题与说明文案，不显示保存、取消按钮。
2. 关闭 `SheetContent` 的通用右上角关闭按钮。
3. 在抽屉底部增加独立操作栏，按钮顺序为“取消”在左、“保存”在右。
4. 操作按钮继续使用项目国际化框架中的 `common.cancel` 与 `common.save`，不在组件中硬编码中文。
5. 保留现有保存、取消事件处理、表单校验、提交状态和数据接口逻辑不变。

## 4. UI 与交互规范

- 操作栏位于抽屉底部，使用顶部边框与表单内容分隔。
- 操作按钮右对齐，保存按钮为主操作样式，取消按钮为次要描边样式。
- 保存过程中沿用既有加载状态并禁用保存按钮。
- 取消继续触发现有关闭确认逻辑，不改变未保存表单的处理方式。
- 页面布局、表单字段、右侧配置说明及其他功能模块保持不变。

## 5. 验收标准

- 新建内容规则页面右上角不显示关闭 X 按钮。
- 编辑内容规则页面右上角不显示关闭 X 按钮。
- 保存、取消按钮均显示在抽屉底部右侧。
- 按钮文案通过项目国际化框架提供，中文 UTF-8 正常，不出现 `�`。
- 点击保存、取消后的既有业务行为保持不变。
- 不修改其他功能模块。

- 用户提供的内容规则新建页面截图作为最终布局依据：
  `https://hebbkx1anhila5yf.public.blob.vercel-storage.com/image-wt1rBJ1z3m8DDjZtfFCQfAnlzT4Lu0.png`

- 乱码自检：本需求文档使用 UTF-8 编码，完成后执行 `�` 字符搜索。

## 7. 变更范围

仅覆盖内容规则新建/编辑抽屉的操作按钮位置与右上角关闭入口；不扩展到内容规则列表、其他安全模块、接口、数据模型、权限或国际化框架之外的功能。
